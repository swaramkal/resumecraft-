# ResumeCraft — Premium Resume Builder & Career Platform

ResumeCraft is a complete, static-hosting-ready career suite built with **HTML5**, **CSS3**, **Vanilla ES6+ JavaScript**, and **HTML2PDF.js**.

## Deploying to GitHub Pages

1. Extract `ResumeCraft.zip`.
2. Create a new repository on GitHub (e.g., `resumecraft`).
3. Upload all files and folders (`index.html`, `css/`, `js/`, etc.) to the root of your repository.
4. Open **Settings → Pages**, select **Deploy from a branch** (`main` / `root`), and click **Save**.
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
